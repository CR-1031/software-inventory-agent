# Руководство пользователя

## Агент инвентаризации программного обеспечения

### 1. Назначение программы

Агент инвентаризации ПО предназначен для автоматического сбора информации об установленных программах на компьютере под управлением Windows.

**Возможности программы:**
- Сканирование реестра Windows
- Сбор информации: название, версия, издатель, дата установки
- Формирование отчета в формате JSON
- Сохранение отчета в файл
- Отправка отчета на сервер (опционально)

---

### 2. Системные требования

| Компонент | Минимальные требования |
|-----------|----------------------|
| Операционная система | Windows 10 / 11 (64-bit) |
| Процессор | 1 ГГц |
| Оперативная память | 256 МБ |
| Свободное место на диске | 10 МБ |
| Дополнительно | Python 3.8 или выше |

### 3. Установка

#### 3.1. Установка Python (если не установлен)

1. Скачайте Python с официального сайта: https://python.org/downloads/
2. Запустите установщик
3. **Обязательно** поставьте галочку "Add Python to PATH"
4. Нажмите "Install Now"

#### 3.2. Скачивание агента

1. Скачайте репозиторий с GitHub: https://github.com/ваш-аккаунт/software-inventory-agent
2. Нажмите зеленую кнопку "Code" → "Download ZIP"
3. Распакуйте ZIP-архив в любую папку

#### 3.3. Установка зависимостей
