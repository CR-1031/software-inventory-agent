# Software Inventory Agent

Агент для инвентаризации программного обеспечения на ПК с Windows.

## Цель проекта
Разработка легковесного агента, который собирает информацию об установленном ПО и формирует отчет для системного администратора.

## Технологии
- Python 3.10+
- WMI / winreg
- JSON / CSV

## Модель разработки
Agile (Scrum) — итеративная разработка с демонстрацией результатов после каждого спринта.

## Структура проекта
- `/docs` — документация
- `/src` — исходный код
- `/tests` — тесты
