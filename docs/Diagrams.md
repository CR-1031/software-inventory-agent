### Актеры

| Актер                   | Описание                             |
| ----------------------- | ------------------------------------ |
| Системный администратор | Запускает агента, анализирует отчеты |

### Варианты использования

| Use Case                   | Описание                                    | Приоритет |
| -------------------------- | ------------------------------------------- | --------- |
| Запустить сканирование     | Агент сканирует реестр и собирает список ПО | Высокий   |
| Сохранить отчет в файл     | Результат сохраняется в JSON-файл           | Высокий   |
| Посмотреть отчет в консоли | Вывод результатов в командную строку        | Средний   |
| Отправить отчет на сервер  | Отправка данных по HTTP                     | Низкий    |
| Настроить конфигурацию     | Изменение параметров через config.json      | Средний   |
| Просмотреть лог ошибок     | Чтение agent.log                            | Средний   |

### Связи между классами

| Связь               | Тип         | Описание                         |
| ------------------- | ----------- | -------------------------------- |
| main → scanner      | Зависимость | main вызывает scanner            |
| main → reporter     | Зависимость | main вызывает reporter           |
| scanner → Software  | Агрегация   | scanner создает объекты Software |
| reporter → Software | Зависимость | reporter использует Software     |
