# Техническое задание
## Агент инвентаризации программного обеспечения

### 1. Цель и назначение
Разработка агента для автоматического сбора информации об установленном программном обеспечении на ПК с Windows. Система предназначена для системных администраторов с целью контроля лицензионной чистоты.

### 2. Функциональные требования
| ID | Требование |
|----|-----------|
| F1 | Сканирование установленного ПО через реестр Windows (HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall) |
| F2 | Сбор атрибутов: название, версия, издатель, дата установки |
| F3 | Формирование отчета в формате JSON |
| F4 | Отправка отчета на сервер по HTTP (опционально) |
| F5 | Работа через командную строку (CLI) |

### 3. Нефункциональные требования
| ID | Требование | Значение |
|----|-----------|----------|
| P1 | Время сканирования | ≤ 30 сек |
| P2 | Потребление памяти | ≤ 50 МБ |
| S1 | Язык реализации | Python 3.8+ |
| S2 | Контроль версий | Git |

### 4. Состав ПО
software-inventory-agent/
├── docs/ # документация
├── src/agent/
│ ├── scanner.py # сканирование реестра
│ ├── reporter.py # формирование JSON-отчета
│ ├── sender.py # отправка на сервер
│ ├── logger.py # логирование
│ └── main.py # точка входа
├── tests/ # тесты
└── README.md
### 5. Интерфейс командной строки
| Команда | Описание |
|---------|----------|
| `python main.py --scan` | Сканирование и вывод в консоль |
| `python main.py --scan --output report.json` | Сохранение в файл |
| `python main.py --scan --send http://server/api` | Отправка на сервер |

### 6. Критерии приемки
- [ ] Агент успешно сканирует ПО на Windows 10/11
- [ ] Отчет формируется в формате JSON
- [ ] Время сканирования не превышает 30 секунд
- [ ] Код размещен в Git-репозитории
- [ ] Написана документация
