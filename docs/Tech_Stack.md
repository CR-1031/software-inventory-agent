# Выбор стека технологий

## Агент инвентаризации программного обеспечения

### 1. Язык программирования

| Критерий                  | Python 3.10+        | C#                   | PowerShell |
| ------------------------- | ------------------- | -------------------- | ---------- |
| Простота разработки       | ✅ Высокая          | Средняя              | Высокая    |
| Кроссплатформенность      | ✅ Да               | Нет (только Windows) | Нет        |
| Работа с реестром Windows | ✅ winreg (встроен) | Да                   | Да         |
| Скорость разработки       | ✅ Быстрая          | Средняя              | Быстрая    |
| Поддержка тестирования    | ✅ pytest           | NUnit                | Pester     |

**Итоговое решение:** Python 3.10+

- Встроенная библиотека `winreg` для работы с реестром
- Простота написания и отладки кода
- Легко создавать отчеты в JSON
- Встроенное логирование

### 2. Библиотеки и модули

| Модуль     | Назначение                       | Тип                       |
| ---------- | -------------------------------- | ------------------------- |
| `winreg`   | Чтение реестра Windows           | Встроенный                |
| `json`     | Формирование отчетов             | Встроенный                |
| `logging`  | Логирование ошибок               | Встроенный                |
| `argparse` | Парсинг командной строки         | Встроенный                |
| `os`       | Работа с файловой системой       | Встроенный                |
| `platform` | Получение имени компьютера       | Встроенный                |
| `datetime` | Дата и время сканирования        | Встроенный                |
| `requests` | Отправка на сервер (опционально) | Внешний (устанавливается) |

### 6. Обоснование выбора

1. **Python** — позволяет быстро реализовать прототип, не требует компиляции
2. **Встроенные библиотеки** — минимизируют зависимости, программа работает "из коробки"
3. **winreg** — нативный доступ к реестру Windows без установки дополнительного ПО
4. **Markdown** — документация читается прямо на GitHub
