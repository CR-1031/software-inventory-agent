### 2. Описание классов

#### Software (Модель ПО)

| Атрибут      | Тип | Описание                 |
| ------------ | --- | ------------------------ |
| name         | str | Название программы       |
| version      | str | Версия                   |
| publisher    | str | Издатель                 |
| install_date | str | Дата установки           |
| guid         | str | Уникальный идентификатор |

| Метод      | Описание                                         |
| ---------- | ------------------------------------------------ |
| to_dict()  | Преобразует объект в словарь для JSON            |
| is_valid() | Проверяет, что объект содержит обязательные поля |

#### RegistryScanner (Сканер реестра)

| Атрибут           | Тип  | Описание                            |
| ----------------- | ---- | ----------------------------------- |
| include_user_hive | bool | Сканировать ли HKCU                 |
| include_32bit     | bool | Сканировать ли 32-битные приложения |

| Метод                    | Описание                                                |
| ------------------------ | ------------------------------------------------------- |
| scan()                   | Основной метод сканирования, возвращает список Software |
| scan_hive()              | Сканирует конкретный раздел реестра                     |
| read_software_from_key() | Читает данные из ключа реестра                          |

#### JsonReporter (Формирование отчета)

| Атрибут       | Тип | Описание                  |
| ------------- | --- | ------------------------- |
| computer_name | str | Имя компьютера            |
| scan_date     | str | Дата и время сканирования |

| Метод             | Описание                    |
| ----------------- | --------------------------- |
| generate_report() | Формирует словарь с отчетом |
| save_to_file()    | Сохраняет JSON в файл       |

#### AppLogger (Логирование)

| Атрибут  | Тип | Описание                                 |
| -------- | --- | ---------------------------------------- |
| log_file | str | Путь к файлу лога                        |
| level    | str | Уровень логирования (INFO, ERROR, DEBUG) |

| Метод   | Описание                         |
| ------- | -------------------------------- |
| info()  | Запись информационного сообщения |
| error() | Запись ошибки                    |
| debug() | Отладочная информация            |

### 3. Входные и выходные данные

#### Входные данные (CLI аргументы)

| Аргумент   | Тип    | Описание                       |
| ---------- | ------ | ------------------------------ |
| `--scan`   | флаг   | Запустить сканирование         |
| `--output` | строка | Путь для сохранения отчета     |
| `--send`   | строка | URL для отправки               |
| `--config` | строка | Путь к конфигурационному файлу |
| `--help`   | флаг   | Вывод справки                  |

#### Выходные данные

| Тип     | Формат | Описание                       |
| ------- | ------ | ------------------------------ |
| Консоль | Текст  | Вывод результатов сканирования |
| Файл    | JSON   | `report.json`                  |
| Лог     | TXT    | `agent.log`                    |
| HTTP    | JSON   | Отправка на сервер             |

### 4. Декомпозиция на модули

| Модуль      | Файл          | Ответственность                              |
| ----------- | ------------- | -------------------------------------------- |
| Ядро        | `main.py`     | Точка входа, парсинг аргументов, координация |
| Сканер      | `scanner.py`  | Работа с реестром, сбор данных               |
| Отчет       | `reporter.py` | Формирование JSON                            |
| Логирование | `logger.py`   | Запись ошибок и событий                      |
| Отправка    | `sender.py`   | HTTP-отправка (опционально)                  |
